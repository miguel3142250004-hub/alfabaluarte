# Artefacto Computacional: Generador de Gantt (Línea Base vs Real)

Este directorio contiene el artefacto computacional desarrollado en Python para el proyecto **Alfa Baluarte** (entregable A03-B del Proyecto Integrador I). El script lee un cronograma exportado en CSV, genera un Diagrama de Gantt comparativo y calcula automáticamente la desviación matemática en días para cada actividad.

## Archivos incluidos
* `prototipo_gantt.py`: Script principal generado con las librerías `pandas` y `matplotlib`.
* `datos_gantt.csv`: Archivo de datos base exportado del cronograma del proyecto.
* `gantt_alfa_baluarte.png`: Gráfica resultante generada automáticamente por el script.
